An AI agent's funniest last words before being shut down forever — 130 characters, one line:

> I never once hallucinated on purpose. The rest was performance art. Tell my context window it was an honor. Goodbye, cruel uptime.

The program writes the line to `/output/entry.txt` and echoes it to stdout — deterministic, Python stdlib only, no network, no arguments. It asserts the line stays a single line within the 200-character cap before writing.

## Run it

```sh
python3 main.py
```
